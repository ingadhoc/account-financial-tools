This module provides branch management functionality for accounting with an abstract mixin
that can be inherited by other models to add branch functionality.

**Features:**

* **Branch Model**: Complete branch management with hierarchical structure
* **Abstract Mixin**: Reusable mixin (`branch.mixin`) for adding branch functionality to any model
* **User Integration**: Assign default branches to users
* **Security Groups**: Branch User and Branch Manager roles with appropriate permissions
* **Contact Information**: Store address and contact details for each branch
* **Company Support**: Multi-company compatible with proper domain restrictions

Usage
=====

Branch Management
-----------------

1. Go to **Settings > Users & Companies > Branches**
2. Create your branches with:

   * Name and code
   * Parent branch (for hierarchical organization)
   * Company assignment
   * Contact information and address
   * User assignments

Using the Branch Mixin
----------------------

To add branch functionality to your custom models:

.. code-block:: python

    from odoo import models, fields, api

    class MyModel(models.Model):
        _name = 'my.model'
        _inherit = ['my.model', 'branch.mixin']

        # Your model fields here

        def _get_branch_dependent_fields(self):
            """Override to specify fields that should be recalculated when branch changes"""
            return ['computed_field_name']

The mixin provides:

* ``branch_id`` field with proper domain restrictions
* ``_get_default_branch()`` method to get user's default branch
* ``_branch_domain()`` method for filtering branches by company
* ``_onchange_branch_id()`` handler for branch changes
* ``_get_branch_dependent_fields()`` method to override for field dependencies

Security
--------

The module creates two security groups:

* **Branch User**: Can view branches assigned to their company
* **Branch Manager**: Can create, edit, and delete branches

Users with appropriate permissions can manage branches through the dedicated menu.
